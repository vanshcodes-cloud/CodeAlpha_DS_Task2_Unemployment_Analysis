# 📊 CodeAlpha Task 2 - Unemployment Analysis with Python

This project is completed as part of the **CodeAlpha Data Science Internship – Task 2**.

The project focuses on analyzing unemployment rate data in India using Python. It includes data cleaning, exploratory data analysis, data visualization, COVID-19 impact analysis, and identification of unemployment trends and regional patterns.

## 🎯 Objectives

- 🧹 Clean and preprocess unemployment data
- 🔍 Explore the dataset and understand its structure
- 📈 Analyze unemployment trends over time
- 🏙️ Analyze unemployment across different regions
- 🌾 Compare Rural and Urban unemployment
- 🦠 Investigate the impact of COVID-19 on unemployment
- 📊 Analyze employment and labour participation trends
- 🗺️ Perform extended analysis using the second unemployment dataset
- 💡 Identify important patterns and insights

## 📂 Project Files

| File | Description |
|---|---|
| `CodeAlpha_DS_Task2_Unemployment_Analysis.ipynb` | Complete Python analysis notebook |
| `Unemployment in India.csv` | Main unemployment dataset |
| `Unemployment_Rate_upto_11_2020.csv` | Extended unemployment dataset for 2020 |
| `requirements.txt` | Python libraries required to run the project |

## 🛠️ Technologies & Libraries

- 🐍 Python
- 🐼 Pandas
- 🔢 NumPy
- 📊 Matplotlib
- 🎨 Seaborn
- 📓 Jupyter Notebook

## 📊 Analysis Performed

### 1. 🧹 Data Cleaning

- Checked missing values
- Removed duplicate records
- Cleaned column names
- Converted date columns
- Prepared the datasets for analysis

### 2. 🔍 Exploratory Data Analysis

- Dataset structure and statistics
- Unemployment rate distribution
- Employment analysis
- Labour participation analysis

### 3. 📈 Data Visualization

- Overall unemployment trends
- Region-wise unemployment analysis
- Rural vs Urban comparison
- COVID-19 unemployment comparison
- Employment trends
- Labour participation trends
- Correlation heatmap

### 4. 🦠 COVID-19 Impact Analysis

The project compares unemployment rates before and during the COVID-19 period to understand changes in unemployment levels during the pandemic.

### 5. 📅 Extended 2020 Analysis

The second dataset is used to analyze additional unemployment data from 2020 and study:

- Extended unemployment trends
- Region-wise unemployment rates
- Differences in unemployment across regions

## 💡 Key Insights

The analysis provides insights into:

- Changes in unemployment rates over time
- Regional differences in unemployment
- Rural and Urban unemployment patterns
- Employment and labour participation trends
- Changes in unemployment during the COVID-19 period

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project folder

```bash
cd CodeAlpha_DS_Task2_Unemployment_Analysis
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

### 4. Open the Jupyter Notebook

```bash
jupyter notebook CodeAlpha_DS_Task2_Unemployment_Analysis.ipynb
```

Run the notebook cells from top to bottom.
